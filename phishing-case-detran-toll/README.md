# Phishing Case — Brazilian Toll Road Phishing (DETRAN Impersonation)

An email impersonating DETRAN, Brazil's traffic authority, pressured recipients over a fake
unpaid toll charge to steal payment credentials. Header, sender, and URL analysis confirmed it
as phishing.

**Verdict:** True Positive — Escalated to L2 SOC
